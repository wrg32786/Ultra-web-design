# Agent Instructions

## Source of truth

`skills/ultra-web-design/modules/` is the editable source of truth. `skills/ultra-web-design/SKILL.md` is generated by `python scripts/build_skill.py`; do not hand-edit it.

The files under `skills/ultra-web-design/templates/` are extracted conveniences. When a template changes in module `08-templates.md`, update the corresponding file in the same change.

## Before editing

1. Read the relevant section of the canonical skill completely.
2. Trace any rule to the authority hierarchy in Section 3.
3. Prefer deletion or reconciliation over adding another overlapping rule.
4. Preserve project-specific choice. Do not turn a contextual heuristic into a universal aesthetic ban.

## Adding or updating a source repository

A source belongs here only when it changes a real website-design or implementation decision.

Record all of the following:

- Repository and exact commit SHA
- License
- Canonical files inspected
- Design-changing contribution
- Conflicts with existing doctrine
- Material integrated
- Material rejected and why

Then update:

- Frontmatter `source_snapshots`
- Section 0.1 ingestion scope
- Section 40 ingestion report
- Section 41 synthesis/conflict resolution
- Section 42 provenance and licenses
- `NOTICE.md`
- `CHANGELOG.md`
- Version and `last_verified`

## Quality rules

- No fabricated metrics, standards, compatibility claims, licenses, or source coverage.
- No placeholder omissions in requested full files.
- No dependency for validation unless the standard library is insufficient.
- No duplicated style recipe that is already represented by a bounded preset.
- No visual prescription without fit, non-fit, responsive behavior, and accessibility/performance risks.
- Keep the skill modular: core doctrine always active, specialist material loaded on demand.

## Required check

Run:

```bash
python scripts/build_skill.py
python scripts/validate.py
```

A change is incomplete until the validator passes and the changelog reflects user-visible behavior changes.
