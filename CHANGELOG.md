# Changelog

All notable changes to Ultra Web Design are recorded here.

## 2.0.1 — 2026-08-22

- Rewrote the README opening and navigation around the public AI web design use case
  while preserving the evidence-first beta status.
- Added canonical GitHub description, homepage, topic, and social-preview metadata.
- Added a crawlable semantic GitHub Pages site with canonical URLs, visible source
  facts, Open Graph and social metadata, JSON-LD, a sitemap, and explicit crawler
  permissions for major search and AI-search bots.
- Added `CITATION.cff`, CodeMeta, root `llms.txt`, a verified source profile, and a
  public-release/indexing checklist.
- Added a deterministic Pages builder that publishes the existing visual fixtures
  with page-specific canonical, social, and structured metadata.
- Added a read-only Pages deployment workflow that remains inactive while the
  repository is private.
- Extended validation to cover public discovery, citation, crawler, structured-data,
  sitemap, social-preview, and Pages packaging.

## 2.0.0 — 2026-08-22

- Replaced the 200 KB always-loaded skill with a 274-line runtime router using
  progressive disclosure.
- Moved the complete synthesis into generated `MANIFEST.md` while preserving every
  source module and provenance record.
- Made `SKILL.md` compliant with the official Agent Skills frontmatter schema;
  custom version, status, repository, and manifest values now live under string
  metadata.
- Added explicit task-size routing so tiny fixes avoid the full website workflow.
- Made runtime authority explicit and classified uncalibrated numeric jury scores
  as advisory review heuristics rather than scientific release thresholds.
- Replaced CI auto-commits with read-only validation that fails on generated drift.
- Added exact template extraction and synchronization checks.
- Added six realistic output evals, twenty positive/near-miss trigger queries, and
  a documented with-skill versus baseline evaluation protocol.
- Added three dependency-free responsive visual fixtures with committed desktop
  and mobile render evidence.
- Relabeled maturity as beta until trigger, output, cost, and real-project criteria
  are demonstrated.

## 1.1.0 — 2026-08-21

- Integrated `Leonxlnx/taste-skill` at commit
  `843c8dd4d18ccff0d5a9cd4b0b71d7dbf7278293`.
- Added the design-read protocol and project-specific variance, motion, and density
  dials.
- Added image-first reference generation, comp extraction, and a reference-comp
  bible.
- Added redesign preservation inventory and modernization order.
- Added bounded style-preset contracts and contextual AI-tell review.
- Added completeness controls while rejecting universal style bans and mandatory
  spectacle.
- Packaged the manifest as the original monolithic `ultra-web-design` Agent Skill
  with working templates and structural validation.

## 1.0.0 — 2026-08-21

- Created the original synthesis from Impeccable, UI/UX Pro Max, Emil Kowalski
  Skills, official GSAP Skills, Awesome DESIGN.md, and Open Design.
- Established the end-to-end operating loop, authority hierarchy,
  business/content architecture, visual craft, interaction, responsive behavior,
  accessibility, performance, SEO, security, privacy, analytics, CMS,
  localization, critique, and release gates.
- Added copy-ready project contracts and a repository-by-repository ingestion
  report.
