# Visual Fixtures

These three self-contained HTML fixtures provide visible evidence that the skill's
shared doctrine can produce materially different business-site worlds without a
fixed framework, component library, external font, stock image, or motion runtime.

They are **illustrative concepts**, not client work and not proof of conversion or
commercial performance.

| Fixture | Surface mode | Governing world | What it demonstrates |
|---|---|---|---|
| `precision-saas/` | Persuade + Operate | Precision instrument / annotated ledger | Product mechanism as proof, no invented social proof, restrained signal color, operational detail |
| `local-service/` | Persuade | Field guide / tree-ring site map | Local context, service-decision clarity, non-SaaS composition, verified-detail placeholders instead of fabricated credentials |
| `editorial/` | Read + Persuade | Independent field journal | Reading hierarchy, issue archive, sponsor disclosure, membership after value, distinct editorial pacing |

Each fixture directory contains one semantic, responsive, dependency-free
`index.html`. `evidence.webp` is a reviewed contact sheet downsampled from desktop
and mobile browser renders of all three fixtures.

The evidence image is not an automated pixel baseline. Future behavioral evals
should compare agent outputs against the brief and assertions rather than forcing
every design to match these aesthetics.
