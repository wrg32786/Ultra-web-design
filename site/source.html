What the project does

Ultra Web Design governs website work from product truth through production release. It covers business strategy, offers, content architecture, proof, visual direction, typography, color, imagery, layout, components, forms, motion, responsive adaptation, accessibility, performance, SEO, security, privacy, analytics, CMS operations, localization, audits, and release QA.

The runtime first classifies the task. Tiny fixes take a short path. Substantial redesigns and greenfield sites load the modules required for preservation, research, direction, implementation, and rendered verification.

What the project does not claim

  • It is not a component library, theme, hosted website builder, or fixed frontend stack.
  • It does not guarantee ranking, conversion, accessibility conformance, or a unique design without correct implementation and evidence.
  • Its example sites are illustrative concepts, not customer work, testimonials, or measured case studies.
  • It does not claim to outperform a baseline until the evaluation protocol produces the corresponding artifacts.
  • It does not grant permission to copy proprietary brand identities, fonts, code, or assets found in references.

Evidence available for inspection

  • Spec-valid lean runtime with explicit task routing and hard truth, security, accessibility, and completion rules.
  • Complete reference manifest generated deterministically from ten ordered modules.
  • Evaluation protocol, six output cases, and twenty trigger queries.
  • Three responsive visual fixtures covering SaaS, local services, and editorial work.
  • Pinned source snapshots and licenses for the seven repositories synthesized into the corpus.
  • Read-only CI that compiles scripts, rebuilds generated artifacts, validates official Agent Skills metadata, and rejects drift.
